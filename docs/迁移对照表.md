## 依赖变化

| 旧依赖 | 用途 | 新的做法 |
| --- | --- | --- |
| `tkinter` | 画板、快捷方式生成器、文件树 GUI | 命令行化；画板改用 Fyne |
| `flask` | 性能监视器 | Go `net/http` + SSE |
| `fastapi` + `uvicorn` + `pydantic` | 文件共享服务 | Go `net/http` + `archive/zip` |
| `psutil` | CPU/内存/磁盘信息 | [`gopsutil`](https://github.com/shirou/gopsutil) |
| `wmi` / `GPUtil` | Windows 硬件信息 | gopsutil + PowerShell CIM |
| `pyudev` | Linux USB 枚举 | 直接读 `/sys/bus/usb/devices` |
| `pygame` | 雷达点云可视化 | 未迁移 |
| `rclpy` / `ros2` | ROS2 话题扫描 | 未迁移 |
| `numpy` / `opencv` | 模型转换与检测 | 未迁移 |

**收益**：目标机器不再需要 Python 环境、pip 依赖或 MSYS2；单个可执行文件即可运行。

## 未迁移的三项及原因

### 1. `ros2_helper/`

ROS2 话题扫描工具强依赖 `rclpy`（ROS2 Python 客户端库）。
用 Go 重写需要 `rclgo` 或自研 DDS 实现，成本远高于收益。

**现状**：源码保留在 `legacy/python/RDK_USB扫描/../` 之外的
`docs/ros2/README.md` 与原始说明里，需要时按原方式运行：

```bash
pip install -r requirements.txt
pip install -e .
ros2-helper
```

### 2. `雷达/`（`COM3_link.py` / `decode.py` / `display.py`）

串口读取 + 协议解码 + Pygame 点云渲染，是**特定硬件的专用链路**，
且解码协议属于外部资料而非本仓库自有逻辑。

**现状**：源码保留在 `legacy/python/`，可按原样使用。

### 3. `onnx_to_om/`

昇腾 NPU 模型转换依赖**昇腾官方 ATC 工具链**（闭源二进制），
Python 部分只是调用它，换 Go 没有意义。

**现状**：教程保留在 [`docs/tutorials/昇腾模型转换教程.md`](tutorials/昇腾模型转换教程.md)。

## 行为变化提示

| 项目 | 旧行为 | 新行为 |
| --- | --- | --- |
| 文件树 | tkinter 窗口 + 交互式输入 | 命令行参数 + 输出到 stdout（可重定向） |
| 磁盘读取速度 | 需 `sudo` 才能清缓存 | 同上，但会明确提示缓存是否清成功 |
| 局域网扫描 | 三份脚本，行为各不相同 | 统一为一个引擎，两阶段扫描（先发现后补全） |
| 系统信息 | `--json <target>` 位置参数 | `--json --target <t>` 开关式 |
| 快捷方式 | 只生成 `.bat` | 按平台自动选择，额外支持 `.url` / `.desktop` |
| USB 列表 | 需装 pyudev / pywin32 | 零依赖，读 sysfs / 调 PowerShell |
| 服务端口 | 固定端口 | 默认端口 + `-addr` / `-port` 可改 |
| 密钥 | 明文写在源码里 | 统一走环境变量（归档时已把明文 key 替换掉） |
