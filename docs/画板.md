# 画板（paint）

> ⬅️ [返回文档首页](index.md) · ➡️ 下一篇：[构建发布](构建发布.md)

一个独立的小画板程序，迁移自旧版的 tkinter 画板，改用 Fyne 实现。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 自由笔画 | 按住左键拖动即可绘制，圆头笔触 |
| 选颜色 | 打开 Fyne 颜色选择器 |
| 调粗细 | 滑块，范围 1–50 |
| 清空画布 | 一键恢复白底 |
| 导出 PNG | 另存为 `.png` 文件 |
| 分辨率记忆 | 配置存在用户配置目录，下次启动沿用 |

---

## 运行

```bash
go build -ldflags "-H windowsgui" -o paint.exe ./cmd/paint
./paint.exe
```

Linux 上同样需要 OpenGL 运行库：

```bash
sudo apt install libgl1-mesa-dev xorg-dev
```

---

## 配置文件

位于**用户配置目录**，不在程序目录（避免污染 exe 旁边）：

| 平台 | 路径 |
| --- | --- |
| Windows | `%AppData%\prompt-merger-toolbox\paint.json` |
| Linux | `~/.config/prompt-merger-toolbox/paint.json` |

内容：

```json
{
  "resolution": "800x600",
  "brush_color": "#0000ff",
  "brush_size": 3
}
```

---

## 实现要点

- 画布是内存里的 `image.RGBA`，控件层只负责把拖拽坐标映射到像素坐标
- 笔触用 Bresenham 直线 + 实心圆点叠加，粗细由圆的半径决定
- 控件用 `ImageFillStretch` 铺满，因此窗口缩放不会让笔画错位
- 配置用 `encoding/json` 读写，失败时回落到默认值，不阻塞启动
