打开 .pgm + .yaml 地图
把 .pgm 与同名 .yaml 一起拖进页面，或点击下方按钮选择。
有 .yaml 时启用比例尺与真实距离测量；只拖入 .yaml 会打开 YAML 编辑器， 只拖入 .pgm 也能预览 / 擦除 / 下载，距离按像素显示。

YAML 编辑器 map.yaml
常用字段：image 对应的 .pgm 文件名 · resolution 米/像素 · origin: [x, y, yaw] 地图左下角位姿 · negate 0/1 · occupied_thresh / free_thresh 0~1。
校验只解析 map_server 常用字段；下载会保留你编辑后的完整文本。
