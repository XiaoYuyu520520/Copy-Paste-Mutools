结果怎么看

  • canPlayType：媒体元素能否播放。probably 基本可用，maybe 需实际加载验证，空表示不支持。
  • MSE：Media Source Extensions 能否用于该容器/编码（流媒体常用）。
  • WebCodecs：能否直接用 VideoDecoder / VideoEncoder 解码或编码。
  • HEVC（H.265）受专利与系统解码器影响，Chrome/Edge 在部分平台需要硬件支持。
  • AV1 软解较普遍，AV1 硬件编码仅较新设备支持。
  • WebCodecs 需要安全上下文（HTTPS 或 localhost）。
