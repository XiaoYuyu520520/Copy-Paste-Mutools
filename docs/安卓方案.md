# Android App 设计与实施计划

> 目标：把**手机上真正有意义**的功能打包成一个 Android APK，由 GitHub Actions 构建。
>
> **状态：已实现。** 入口 `cmd/android`，界面 `internal/mobile`，
> 工作流 [`.github/workflows/android.yml`](../.github/workflows/android.yml)。
> 当前产出 **arm64-v8a + Debug 自签名** APK。

---

## 一、功能取舍（先想清楚什么不该上手机）

现有 15 个工具里，有一半依赖桌面系统能力。逐条评估：

| 功能 | Android 可用性 | 结论 | 原因 |
| --- | --- | --- | --- |
| 提示词 + 语句合并（多标签） | ✅ 完全可用 | **保留（核心）** | 纯逻辑，`internal/data` 零平台依赖 |
| AI 聊天（OpenAI 兼容流式） | ✅ 完全可用 | **保留** | 纯 HTTP + SSE；手机端反而更常用 |
| Markdown / 地图预览 | ⚠️ 需 WebView | **暂未实现** | 当前手机端没有 WebView 组件；不要声称已支持 |
| 画板 `paint` | ✅ 很适合触屏 | **保留** | Fyne 触摸事件天然适配 |
| 局域网扫描 `netscan` | ⚠️ 需改造 | **保留（改 TCP）** | Android 没有可用 `ping` 可执行文件、ARP 表自 Android 10 起不可读 |
| 系统信息 `sysinfo` | ✅ 部分可用 | **保留（精简）** | gopsutil 的 `/proc` 路径在 Android 上有效；磁盘分区信息受限 |
| 文件共享 `share` | ✅ 可用 | **保留（进「本地服务」）** | 手机当 HTTP 服务器；存储用应用私有目录 + SAF 选择器 |
| 性能监视 `monitor` | ✅ 可用 | **保留（进「本地服务」）** | 本地 HTTP + SSE，看板机负载很实用 |
| 网速测试 `netspeed` | ✅ 可用 | **保留（进「本地服务」）** | WebSocket + 内嵌前端 |
| 模拟键盘输入 | ❌ 不可用 | **去掉** | Windows `SendInput`，Android 无对应公开 API |
| 桌面快捷方式 `shortcut` | ❌ 无意义 | **去掉** | 生成 `.bat` / `.desktop` |
| USB 枚举 `usb` | ❌ 不可用 | **去掉** | 需要 Android USB Host API + Java 层权限 |
| 磁盘基准 `diskbench` | ⚠️ 意义有限 | **去掉** | 只能在应用私有目录测，参考价值低 |
| 磁盘监控 `diskm` | ❌ 不可用 | **去掉** | `/proc/diskstats` 受限 |
| CPU 基准 `cpubench` | ✅ 可用 | **可选保留** | 纯计算，但手机跑分价值有限，放「工具」页最后 |

**结论：Android App = 编辑器（动态区块 / 拼接模式 / 模板）+ AI 聊天（会话持久化 / 多服务商）+ 画板 + 局域网扫描（TCP）+ 本地服务（共享 / 监视 / 测速）。**

### 已实现能力（与源码一致）

| 能力 | 说明 |
| --- | --- |
| 动态区块 | 新增/删除/复制/上移下移；每块提示词 + 语句 + 标题 |
| 拼接模式 | 自然语言 / 原样 / Markdown / 自定义分隔符 |
| 本地模板 | 保存当前标签为模板、选择应用、`{{变量}}` 填写（`templates.json`） |
| 聊天会话 | 自动保存到 `chat-sessions.json`，重启后恢复最近会话；新建/重命名/清空/删除 |
| 多服务商 | AI 设置页支持新增/切换/删除多个 OpenAI 兼容服务商 |
| 扫描状态机 | 防止重复启动与取消竞态，状态栏显示进度 |

> Markdown / PGM 地图在 Android 端**尚未实现**，相关入口不会出现在界面中。

## 二、技术方案

### 2.1 新增代码（不动桌面版）

```
cmd/android/            # 新入口：Fyne mobile 应用
internal/mobile/        # 移动端 UI（底部导航，触屏优先）
  app.go                # 主窗口 + NavigationBar
  editor.go             # 合并编辑器（复用 internal/data，动态区块 + 模板）
  chat.go               # AI 聊天（原生控件 + 本地会话持久化）
  chat_store.go         # 会话/消息 JSON 持久化
  paint.go              # 画板（复用 internal/toolbox/paint）
  scan_page.go          # 局域网扫描（复用 internal/netscan，强制 TCP）
  services_page.go      # 本地服务（share / monitor / netspeed）
  settings_page.go      # API 配置
```

**为什么单独做 UI 而不是复用 `internal/ui`？**
桌面版是「左侧竖向导航 + 状态栏 + 多标签栏」，在 6 寸屏上会挤成一团。
移动端要的是**底部导航 + 单页面全屏 + 大按钮**。逻辑复用、布局重写，
比给桌面布局打一堆 `if mobile` 补丁干净得多。

### 2.2 平台适配改造（最小改动）

| 位置 | 改动 |
| --- | --- |
| `internal/netscan/ping.go` | 抽出 `systemPingSupported()`；Android 返回 false，直接走 TCP 探测 |
| `internal/netscan` | 增加 `lookupMACS upported()`；Android 跳过 ARP |
| `internal/toolbox/sysinfo` | 磁盘/GPU 采集失败时静默跳过（已如此），无需改 |
| `internal/render/server.go` | 确认监听 `127.0.0.1` 在 Android 可用（可行，回环地址不受限） |

### 2.3 APK 生成

Fyne 自带 Android 打包（`fyne package -os android`），需要：

| 依赖 | 版本 | 来源 |
| --- | --- | --- |
| JDK | 17 | runner 自带 |
| Android SDK | platform 34 | `android-actions/setup-android` |
| Android NDK | r26 (26.1.10909125) | `sdkmanager "ndk;26.1.10909125"` |
| `fyne` CLI | v2.8.0 | `go install fyne.io/fyne/v2/cmd/fyne@v2.8.0` |

命令：

```bash
fyne package -os android/arm64 \
  -app-id com.xiaoyuyu.promptmerger \
  -name "提示词工具箱" \
  -icon ico/icon.png \
  -release=false          # debug 自签名，可直接安装
```

产物：`提示词工具箱.apk`

### 2.4 签名策略

| 阶段 | 方案 |
| --- | --- |
| 日常 / 内测 | **debug 自签名**（Fyne 默认），装到手机上即可用 |
| 正式发布 | 用 GitHub Secrets 存 keystore（base64）+ 别名 + 密码，`fyne package -release -keyStore ...` |

**先做 debug 签名**，让它能装上、能用；需要上架或稳定升级时再补正式签名。

## 三、系列工作流设计

现有两个 workflow 不动，**新增 `android.yml`**：

```yaml
name: Android APK
on:
  push:
    branches: [main]          # 每次合并都出包，方便随时装机测试
    tags: ["v*"]              # tag 时把 APK 附进 Release
  workflow_dispatch:

jobs:
  apk:
    runs-on: ubuntu-latest
    steps:
      - checkout
      - setup-go 1.25
      - setup-java 17 (temurin)
      - setup-android
          + sdkmanager "platforms;android-34" "build-tools;34.0.0" "ndk;26.1.10909125"
      - go install fyne CLI
      - fyne package -os android/arm64 ...
      - 上传 artifact: prompt-merger-toolbox-arm64.apk
```

**为什么只出 `android/arm64`？**
2020 年后发布的 Android 手机 99% 是 arm64。出 arm64 单包能把构建时间减半。
需要兼容老设备时再加 `android/arm`。

## 四、实施阶段

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| **P1** | `internal/netscan` Android 适配（TCP 强制 + 跳过 ARP） | `GOOS=android CGO_ENABLED=0 go build ./internal/netscan` 通过 |
| **P2** | `internal/mobile` 移动端 UI（5 个页面） | 逻辑包 Android 交叉编译通过 |
| **P3** | `cmd/android` 入口 + 应用图标 + `AndroidManifest` 元数据 | 同上 |
| **P4** | `.github/workflows/android.yml` | CI 产出 APK artifact |
| **P5** | 装机实测（编辑器 / AI / 扫描 / 画板 / 本地服务） | 真机能启动、能合并、能聊天 |
| **P6** | 正式签名 + Release 附件 + 文档 | tag 发版时 APK 出现在 Release |

### 风险与对策

| 风险 | 对策 |
| --- | --- |
| 本地没有 NDK，无法本地出 APK | 本地只做 `GOOS=android CGO_ENABLED=0` 编译校验，APK 交给 CI |
| Fyne 在 Android 的 WebView 集成有限 | Markdown / 本地服务页用 `浏览器打开` 退路；先做原生渲染 |
| 局域网扫描在 Android 无 ICMP | 纯 TCP 探测（已规划），端口列表精简为常用 10 个保证速度 |
| 文件共享需要存储权限 | 首版只共享**应用私有目录**，用系统文件选择器导入；后续接 SAF |
| `ubuntu-24.04-arm` runner 可能不可用 | Android 构建在 x86 runner 上交叉编译 arm64（NDK 提供工具链，无需原生 arm） |

## 五、与现有 CI 的关系

```
build.yml      → 桌面/服务端：vet + test + gofmt + 交叉编译冒烟
release.yml    → tag v*：Windows x64 / Ubuntu amd64 / Ubuntu arm64 三平台产物
android.yml    → Android APK（main 每次提交都出包，tag 时附 Release）
```

三条互不阻塞，各自 `fail-fast: false`，任何一条挂掉不影响另外两条的产物。

## 七、实现落点

### 新增文件

```
cmd/android/main.go            # 入口：app.NewWithID + mobile.New
internal/mobile/
  app.go                       # 底部 5 页导航（AppTabs + TabLocationBottom）
  store.go                     # 配置持久化（写进 Fyne 应用存储目录）
  editor.go                    # 提示词合并（复用 internal/data）
  chat.go                      # AI 对话（原生控件 + 流式）
  openaiclient.go              # OpenAI 兼容 SSE 客户端
  scan.go                      # 局域网扫描（复用 internal/netscan）
  paint.go                     # 画板（复用 internal/toolbox/paint）
  more.go                      # AI 设置 / 本地服务 / 系统信息 / 关于
internal/netscan/platform.go   # ICMP / MAC 能力探测（Android 关闭）
.github/workflows/android.yml  # APK 构建 + tag 时附 Release
```

### 改动点

| 文件 | 改动 |
| --- | --- |
| `internal/netscan/scanner.go` | `probeLiveness` 先查 `ICMPProbeSupported()`，Android 跳过必然失败的 ping |
| `internal/netscan/ping.go` | `LookupMAC` 先查 `MACExtractionSupported()`，Android 直接返回空 |
| `internal/toolbox/monitor/monitor.go` | 增加 `Shutdown()`（移动端「停止服务」需要释放端口） |

### 构建方式

```bash
# 本地（需要 Android SDK + NDK）
go install fyne.io/fyne/v2/cmd/fyne@v2.8.0
fyne package -os android/arm64   -src ./cmd/android   -app-id com.xiaoyuyu.promptmerger   -name "提示词工具箱"   -icon ico/icon.png   -app-version 1.1.0 -app-build 1
```

CI 里由 `android.yml` 完成同样的步骤：JDK 17 + Android SDK 34 + NDK 26 → `fyne package` → 上传 artifact。

### 安装

1. 到 Actions 页面下载 `prompt-merger-toolbox-android-arm64` artifact，或到 Release 下载 `提示词工具箱.apk`；
2. 手机上允许「安装未知来源应用」；
3. 直接安装。

> Debug 签名每次构建的证书相同（Fyne 内置），因此后续版本可以覆盖安装。

## 八、已知限制

| 限制 | 说明 |
| --- | --- |
| 无 ICMP | Android 不允许普通应用发 raw socket，扫描只能靠 TCP 握手判断存活 |
| 无 MAC | Android 10 起 `/proc/net/arp` 不可读 |
| 无 WebView 组件 | Markdown 预览用 `widget.NewRichTextFromMarkdown`（Fyne 内置渲染，支持标题/列表/代码块样式） |
| 本地服务需手动打开浏览器 | Fyne 无内嵌浏览器，服务页提供「用浏览器打开」按钮 |
| 文件共享目录 | 首版只能共享应用私有目录（`/data/data/<pkg>/files`），尚无 SAF 选择器 |
| 体积 | Fyne + OpenGL 运行时，APK 约 30–40 MB |
