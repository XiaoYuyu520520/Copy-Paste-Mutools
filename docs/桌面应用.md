# 桌面应用（merger）

> ⬅️ [返回文档首页](index.md) · ➡️ 下一篇：[迁移对照表](迁移对照表.md)

基于 Go + [Fyne](https://fyne.io) 的原生桌面程序，无浏览器内核，单文件部署。

---

## 界面布局

```
┌──────────┬─────────────────────────────────────────────────┐
│          │  标签1  标签2  标签3  ＋                         │
│  编辑器  ├─────────────────────────────────────────────────┤
│  模拟键盘│  提示词 [                                ]      │
│  文件夹  │  ☐ 启用                                          │
│  AI 设置 │                                                  │
│          │  语句   [                                ]      │
│          │  ☑ 启用                                          │
│          ├─────────────────────────────────────────────────┤
│          │  合并预览（只读）                                │
│          │  提示词：                                        │
│ ⚙ 配置   │  你好，                                          │
│          │  世界。                                          │
├──────────┴─────────────────────────────────────────────────┤
│  状态文本                                  [AI聊天][Markdown][LAN]  3 标签 │
└────────────────────────────────────────────────────────────┘
```

- **左侧竖向导航**：编辑器 / 模拟键盘输入 / 文件夹 Tree / AI 设置
- **底部状态栏**：左下角「⚙ 配置」菜单（切换主题），右下角三个工具按钮 + 标签数

## 功能详解

### 编辑器

每个标签 5 行：**提示词** / **语句** 两个多行文本框 + 两个独立复选框。

合并规则（逐行独立判断）：

| 提示词 | 语句 | 输出片段 |
| --- | --- | --- |
| 启用且非空 | 启用且非空 | `提示词：\n语句` |
| 启用且非空 | 关闭或空 | `提示词` |
| 关闭或空 | 启用且非空 | `语句` |
| 关闭或空 | 关闭或空 | 跳过 |

最后把所有片段用 `，\n` 连接，末尾追加 `。`。

**性能**

- 文本输入 → 合并预览：**200 ms 去抖**（不是每键击都重算）
- 编辑 → 写配置文件：**1.5 s 去抖**
- 关闭窗口时同步落盘，不丢数据

### 模拟键盘输入

把任意标签的合并结果**逐字真实键入**到目标程序，绕过「禁止粘贴」的检测。

| 参数 | 说明 |
| --- | --- |
| 启动延迟 | 切换到目标程序后的等待时间 |
| 字符间隔 | 每个字符之间的间隔 |
| 重复次数 | 重复输入几遍 |
| Enter 处理 | **屏蔽** / 替换为 **Ctrl+Enter** / 替换为 **空格** |

> ⚠️ Enter 默认会被屏蔽或替换，否则换行会被直接发出去误触「发送」。
> 底层用 Windows `SendInput` 逐字敲 Unicode。

### 文件夹 Tree

选一个文件夹，按 `tree` 风格输出目录结构。

- 可勾选屏蔽隐藏项（`.git` 等）与常见构建/依赖目录（`build`、`node_modules`…）
- 支持**添加要屏蔽的文件夹名**与**匹配关键词**（名称含即整棵忽略）
- 结果一键复制

### Markdown 渲染

底部一个按钮即在本机**随机空闲端口**起本地服务并打开系统浏览器。

- 左侧粘贴 Markdown 或打开本地 `.md` / `.txt`
- 右侧内嵌 marked + highlight.js，**GitHub 风格实时预览**（代码高亮 + 复制）
- 完全离线，不请求任何 CDN

### 2D 激光 SLAM 地图

打开 `.pgm`（+ 同名 `.yaml`）即被识别为激光地图，浏览器内提供：

- **比例尺**（自动按分辨率计算）
- **测量尺子**（点两点测距离）
- **障碍物擦除橡皮**（在图上涂掉噪点）
- 修改后可**保存下载** `.pgm` / `.yaml`

### 局域网设备扫描

底部「LAN」按钮即在本机随机空闲端口起服务并自动打开浏览器。

- 自动枚举网卡与子网
- CIDR 快捷 `/24` ~ `/26`
- 并发数 / 超时 / 端口可调
- 系统 ping（ICMP 被拦时**自动回退 TCP**）
- 主机名 / MAC / 开放端口
- 表格**实时刷新**，支持**导出 CSV**

### AI 聊天

底部「AI 聊天」按钮起本地服务并打开浏览器，界面参考 RikkaHub：

- 左侧会话列表（新建 / 切换 / 删除，本机 localStorage）
- 顶部模型下拉（自动读取上游 `/models`）
- 消息气泡 + **Markdown 渲染**（代码高亮 / 复制）
- 重新生成 / 复制
- 底部输入框（Enter 发送、Shift+Enter 换行、停止生成）
- 走 **OpenAI 兼容 `/chat/completions` 流式（SSE）**

可接 OpenAI / DeepSeek / Qwen / Moonshot / 本地 Ollama·LM Studio。

### AI 设置

左侧导航的「AI 设置」页，配置 OpenAI 兼容接口：

| 字段 | 说明 |
| --- | --- |
| API 地址 | 如 `https://api.openai.com/v1` |
| API Key | Bearer Key |
| 模型 | 模型名 |
| 系统提示词 | 每轮对话的 system message |

保存进 `config.json` 的 `ai` 段。

### 主题

左下角「⚙ 配置」菜单一键切换亮 / 暗，**记忆到配置**。

界面为 JetBrains / VSCode 取向的暗色 IDE 外观：深墨蓝底 `#1E2333`、
控件底 `#2C3247`、强调色 `#3A96FF`、柔和文本 `#E1E4EB`。

## 配置文件

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| `config.json` | 与 exe 同目录 | 多标签配置 + 主题 + 激活标签 + `ai` 段 |
| `FyneApp.toml` | 与 exe 同目录 | 首次启动自动生成 |

`config.json` 的 `ai` 段示例：

```json
{
  "ai": {
    "base_url": "https://api.openai.com/v1",
    "api_key": "sk-...",
    "model": "gpt-4o-mini",
    "system_prompt": "你是一个贴心的助手"
  }
}
```

> ⚠️ `config.json` 含 API Key，已在 `.gitignore` 中排除，**不会进仓库**。

## 已知限制

- Fyne v2.8 没有公开 `SetTabsClosable` / `OnClosed`，所以项目自带 `customTabBar` 实现；
  将来 Fyne 公开这些 API 后可以把 `tabbar.go` 换成 `container.NewAppTabs`
- macOS 包未做 Apple 签名与公证，首次打开可能需要在 Finder 里右键「打开」
