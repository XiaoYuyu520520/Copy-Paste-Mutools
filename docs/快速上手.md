# 快速上手

> ⬅️ [返回文档首页](index.md) · ➡️ 下一篇：[工具箱](工具箱.md)

5 分钟把工具箱跑起来。

---

## 一、下载现成的包（推荐）

打开 [**Releases**](https://github.com/XiaoYuyu520520/Copy-Paste-Mutools/releases)，
下载对应平台的压缩包：

| 平台 | 下载 |
| --- | --- |
| Windows x64 | `merger-windows-amd64.zip` / `toolbox-windows-amd64.zip` / `paint-windows-amd64.zip` |
| Ubuntu x86_64 | `*-linux-amd64.tar.gz` |
| Ubuntu ARM64 | `*-linux-arm64.tar.gz` |

解压即用：

```powershell
# Windows
Expand-Archive merger-windows-amd64.zip -DestinationPath .\merger
.\merger\merger.exe
```

```bash
# Ubuntu
tar -xzf toolbox-linux-amd64.tar.gz
./toolbox/toolbox --help
```

> Linux 端需要系统提供 X11 / OpenGL 运行库（Fyne 桌面应用需要）：
> `sudo apt install libgl1-mesa-dev xorg-dev`

## 二、自己编译

### 环境要求

| 项 | 要求 |
| --- | --- |
| Go | **1.25+**（`go version` 检查） |
| Windows 编译器 | Fyne 需要 CGO → 装 [MSYS2 UCRT64](https://www.msys2.org/) 并保证 `gcc` 在 PATH 里 |
| Ubuntu 编译器 | `sudo apt install build-essential libgl1-mesa-dev xorg-dev` |

### 编译全部程序

```bash
git clone https://github.com/XiaoYuyu520520/Copy-Paste-Mutools.git
cd Copy-Paste-Mutools

go build -o merger.exe    ./cmd/merger
go build -o toolbox.exe   ./cmd/toolbox
go build -o paint.exe     ./cmd/paint
```

Windows 上想让桌面程序**双击不弹黑色命令行窗口**：

```powershell
go build -ldflags "-H windowsgui" -o merger.exe ./cmd/merger
```

### 跑测试

```bash
go test ./...
```

## 三、试几个命令

```powershell
# 扫一下局域网

# 输出系统信息（JSON，方便贴进文档）
.\toolbox.exe sysinfo --json --target all
```

完整参数见 [工具箱](工具箱.md)。

## 四、桌面应用

```powershell
.\merger.exe
```

首次启动会在 exe 同目录生成 `config.json` 与 `FyneApp.toml`。
界面左侧是页面导航（**编辑器 / 模拟键盘输入 / 文件夹 Tree / AI 设置**），
底部状态栏左下角是「⚙ 配置」菜单（可切换亮/暗主题），
右下角是 **AI 聊天 / Markdown / LAN** 三个按钮。

详细说明见 [桌面应用](桌面应用.md)。

## 五、遇到问题？

| 现象 | 原因与解法 |
| --- | --- |
| `go build` 报 `gcc: executable file not found` | 没装 MSYS2 或 gcc 不在 PATH。装完把 `C:\msys64\ucrt64\bin` 加进 PATH |
| 运行时提示缺 `libGL.so.1` | Ubuntu 上执行 `sudo apt install libgl1-mesa-dev` |
| `netscan` 扫不到设备 | 防火墙屏蔽了 ICMP；用 `-timeout 1500` 放宽，或改用 TCP 探测端口 |
| `diskbench` 读取速度虚高 | 默认不清页缓存，读速度偏乐观；Linux 上可 root 运行并加 `-drop-caches` |
| 想让命令在后台跑 | `toolbox share -addr 0.0.0.0:8000` 后用 `Ctrl+C` 停止 |
