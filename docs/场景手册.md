## 一、写提示词 / 拼指令

| 目标 | 怎么做 |
| --- | --- |
| 把多段提示词拼成一段连续文本 | 编辑器里逐行填「提示词 + 语句」，底部实时预览，满意后「复制结果」 |
| 粘贴一段长文再拆成多行 | 「粘贴」按钮 → 整段落到第一个区块，再手动拆分 |
| 输出干净的代码，不要被中文标点污染 | 拼接模式选 **原样拼接**（不添加任何标点） |
| 输出带标题的 Markdown | 拼接模式选 **Markdown**（每个区块生成 `## 标题` + 段落；空区块自动跳过） |
| 自定义区块之间的分隔内容 | 拼接模式选 **自定义分隔符**，填写分隔串 |
| 复用一套常用提示词 | 编辑器「模板」→ 保存当前为模板 → 之后一键应用 |
| 模板里有些内容每次不同 | 模板里写 `{{项目名称}}`，应用时弹窗填写 |
| 把别人的模板拿过来 | 模板面板「导入 JSON」；自己导出一份做备份用「导出 JSON」 |

### 快捷键（桌面端）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` | 新建标签 |
| `Ctrl+S` | 立即保存配置 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Enter` | 复制当前合并结果 |
| `Ctrl+1..9` | 切换标签 |
| `Ctrl+E` / `Ctrl+D` / `Ctrl+O` | Markdown 页：左右对照 / 亮暗主题 / 打开文件 |

## 二、AI 问答

| 目标 | 怎么做 |
| --- | --- |
| 用 OpenAI / DeepSeek / Qwen / Ollama | 左侧「AI 设置」→ 填 Base URL、Key、模型 → 保存 |
| 同时备着好几套服务 | AI 设置里「新增」多个服务商，随时切换当前使用的那套 |
| 确认接口能不能连通 | AI 设置「测试连接」：会请求上游 `/models` 并显示结果 |
| 免去每次输入 Enter | 模型页「全屏渲染 / 左右对照」旁边就是发送区；停止按钮随时可中断 |
| 手机上接着上次聊 | 手机端会话自动存盘，重开 App 即可恢复；顶部下拉可切换/新建/重命名/删除 |

## 三、看局域网里的设备

| 目标 | 怎么做 |
| --- | --- |
| 找出网段里有哪些设备 | 桌面端底部「LAN」按钮 → 选网段 → 开始扫描 |
| 手机上扫（无 ping 权限） | 手机端「扫描」页，自动改用 TCP 探测 |
| 拿到设备清单给同事 | 扫描页「导出 CSV」 |
| 想知道设备开了哪些服务 | 扫描结果里的端口列（TCP 探测命中即显示） |
| 扫到一半不想扫了 | 点「停止」，旧任务会真正结束，不会和新扫描结果混在一起 |

## 四、测磁盘 / CPU 性能

| 目标 | 怎么做 |
| --- | --- |
| 测磁盘顺序读写 | `toolbox diskbench` |
| 不想被程序删掉文件 | 默认只写临时文件并自动清理；指定 `-file` 时若文件已存在会直接报错，需要覆盖请显式加 `-overwrite` |
| 想要接近真实磁盘的读速度 | 默认不清页缓存（避免影响同机其他程序）；Linux 上可用 root 运行并加 `-drop-caches` |
| 对比两台机器的 CPU | `toolbox cpubench`，分数按同语言版本对比 |

| --- | --- |

## 六、预览文档 / 地图

| 目标 | 怎么做 |
| --- | --- |
| 预览 README | 网页版「Markdown 实时预览」，或桌面端底部「Markdown」 |
| 查看 ROS 激光地图 | 网页版「2D 激光 SLAM 地图」拖入 `.pgm` + `.yaml` |
| 量两点距离 | 选「测量尺子」，点两次；有 `.yaml` 显示米，无则显示像素 |
| 去掉地图噪点 | 选「障碍物擦除」按住拖动；支持撤销/重做，导出前可反复调整 |
| 放大/缩小/平移 | 滚轮缩放（以指针为锚点）、普通模式拖动平移、「适应」/「100%」按钮 |
| 改地图 YAML | 顶部「编辑 YAML」→ 校验 → 下载；也可只拖入 `.yaml` 作为编辑器使用 |

> 地图擦除内容在改变窗口大小、缩放、平移后都会保留，导出的 PGM 即为编辑后的结果。

## 七、离线使用

| 目标 | 怎么做 |
| --- | --- |
| 装桌面版 | [Releases](https://github.com/XiaoYuyu520520/Copy-Paste-Mutools/releases) 下载对应平台压缩包 |
| 装到安卓手机 | [Releases](https://github.com/XiaoYuyu520520/Copy-Paste-Mutools/releases) 下载 APK（arm64-v8a，Debug 签名） |
| 让配置跟着 U 盘走 | 在程序同级目录放一个空的 `portable.txt` 文件（或设环境变量 `PROMPT_MERGER_PORTABLE=1`），配置与模板都写在程序目录 |
| 正常安装时配置在哪 | 用户配置目录：Windows `%AppData%\prompt-merger-toolbox`，Linux `~/.config/prompt-merger-toolbox`；旧版本写在程序目录的配置会自动迁移过来 |
