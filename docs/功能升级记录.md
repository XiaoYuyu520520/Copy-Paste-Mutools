## 批次 2（已完成：正确性与稳定性修复）

### P0 级修复

| 问题 | 位置 | 修复 |
| --- | --- | --- |

### P1 级修复

| 问题 | 位置 | 修复 |
| --- | --- | --- |
| Markdown 模式输出空标题 | `internal/data/merger.go` | 默认跳过空区块；新增 `KeepEmptyHeadings` 保留固定模板结构 |
| 数据路径绑定 exe 目录 | `internal/data/storage.go` | 新增存储策略：默认用户配置目录；`portable.txt` / `PROMPT_MERGER_PORTABLE=1` 启用便携模式；旧配置自动迁移 |

| 扫描取消不等待任务 | `internal/netscan/scanner.go` | 取消时真正 `wg.Wait()`；事件带 `ScanID`；同一 Scanner 拒绝并发扫描 |
| 地图编辑内容丢失 | `docs/tools/mapview.html` | 原图/编辑缓冲/视图三层分离；缩放平移只重绘视图；新增滚轮缩放、拖动平移、适应窗口、100%、撤销/重做 |

### P2 级修复

| 问题 | 位置 | 修复 |
| --- | --- | --- |
