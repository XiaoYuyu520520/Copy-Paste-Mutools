## 批次 4（已完成：三端 UI 交互优化）

### 桌面端（merger）

- 右键菜单：标签右键（重命名 / 复制标签 / 左移右移 / 复制合并结果 /
  关闭此标签 / 关闭其他 / 关闭右侧）、区块行空白处右键（与「⋯」菜单同源）、
  输入框内保留 Fyne 原生剪切 / 复制 / 粘贴菜单
- 区块标题行收敛为「折叠 + ⋯」，四个图标按钮收进菜单，降低视觉噪音
- 标签批量管理：空标签直接关闭（有内容才确认）、复制标签（副本紧跟原标签）、
  左移 / 右移标签并同步配置与控件顺序
- 快捷键：目录化（shortcut_catalog.go），F1 弹一览；新增 Ctrl+Tab 循环切换、
  Ctrl+Shift+N 新增区块、Alt+↑/↓ 移动当前区块、Ctrl+F 聚焦输入框、
  Ctrl+L 定位标签名、Ctrl+Shift+R 重命名、Ctrl+J / Ctrl+Shift+M / Ctrl+Shift+L
  打开浏览器工具；Ctrl+9 跳最后一个标签
- 合并预览框右键换成中文「复制全部」；窗口内容包最小尺寸容器（960×640），
  窄窗口不再把两列输入框挤坏
- 新增 `data.InsertBlock`（在任意位置插入空区块）与对应单测

### 网页工具（docs/tools/）

- 全站亮 / 暗主题：`theme.js` 跟随系统 + 手动切换记忆（localStorage），
  首帧前写入避免闪白；顶栏主题圆钮，Ctrl+Shift+D 全站切换；
  common.css 变量重写（focus-visible、prefers-reduced-motion、打印样式）
- 总览页：工具搜索框（场景关键词可搜、`/` 聚焦、↑↓ 选择、Enter 打开），
  移除重复的场景表
- Base64：即输即出（自动识别编码/解码方向）、拖拽文件、行/字符/字节计量、
  复制按钮即时反馈、完整快捷键（Ctrl+Enter / Ctrl+Shift+Enter / Alt+S / Esc）
- 二维码：Ctrl+Enter 重新生成、Ctrl+S 下载 PNG
- 编解码检测：窄屏表格自动变卡片（data-label 列名）
- 六页导航顺序统一；Markdown 页主题改为跟随站点主题
- CI 增加 `tests/web/check_js_syntax.py`（node --check 校验内联脚本）

### Android 端（internal/mobile）

- 自写底部导航替换 AppTabs：5 个入口等宽常显（Fyne 的 AppTabs 在窄屏会把
  放不下的标签折进「更多」菜单），触控目标 60 dp，选中态圆角底色 + 强调色图标
- 与桌面端共用 `internal/theme` 调色板（新增包），两端观感一致
- 全局保存状态条：底栏上方常驻，任何页面保存失败都可见
  （此前只有编辑页有反馈）
- 编辑页：标签名 / 拼接模式 / 分隔符收进「页面设置」；区块操作收进「⋯」菜单
  （不再平铺 4 个图标按钮，防误触删除）
- 聊天页：新建 / 重命名 / 置顶 / 清空 / 删除收进「⋯」菜单
- 新增 ui_test.go：底栏选中态、页面切换互斥、主题共用、保存失败反馈
