# 工具箱（toolbox）

> ⬅️ [返回文档首页](index.md) · ➡️ 下一篇：[桌面应用](桌面应用.md)

一个可执行文件承载全部小工具。

```bash
toolbox <子命令> [参数]
```

| 子命令 | 一句话说明 |
| --- | --- |
| [`tree`](#tree--打印目录树) | 打印目录树，自动忽略构建/依赖目录 |
| [`cpubench`](#cpubench--cpu-单核基准测试) | CPU 单核性能基准测试 |
| [`diskbench`](#diskbench--磁盘读写吞吐测试) | 磁盘顺序读写吞吐测试 |
| [`diskm`](#diskm--实时磁盘-io-监控) | 实时磁盘 I/O 吞吐监控 |
| [`netscan`](#netscan--局域网设备扫描) | 局域网设备扫描（ICMP/TCP/MAC/主机名） |
| [`sysinfo`](#sysinfo--系统信息) | 系统硬件与资源信息 |
| [`shortcut`](#shortcut--生成网址快捷方式) | 生成桌面网址快捷方式 |
| [`usb`](#usb--usb-设备列表) | 列出 USB 设备，可导出 Markdown |
| [`share`](#share--局域网文件共享) | 局域网文件共享服务 |
| [`monitor`](#monitor--开发板性能监视器) | 开发板性能监视器（SSE） |
| [`netspeed`](#netspeed--局域网网速测试) | 局域网网速测试服务 |

## tree — 打印目录树

```bash
toolbox tree [路径]
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-depth N` | `0`（不限） | 最大递归深度，根目录算第 0 层 |
| `-hidden` | `false` | 设为 true 时**显示**隐藏文件（默认隐藏 `.` 开头） |
| `-no-default-ignore` | `false` | 不忽略常见的构建/依赖目录 |
| `-ignore a,b,c` | 空 | 额外忽略的目录名，逗号分隔 |
| `-keyword x,y` | 空 | 名称包含即整棵忽略的关键词 |

默认忽略：`build` `dist` `out` `bin` `obj` `target` `vendor` `node_modules`
`__pycache__` `Debug` `Release` `x64` `cmake-build-debug`，以及所有 `.` 开头的隐藏项。

```bash
# 只看两层
toolbox tree -depth 2

# 额外屏蔽 dist、tmp，以及名字里带 test 的目录
toolbox tree -ignore "dist,tmp" -keyword "test"
```

统计信息输出到 **stderr**，因此 `toolbox tree > tree.txt` 得到的是干净的树。

## cpubench — CPU 单核基准测试

```bash
toolbox cpubench
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-int-limit N` | `50000` | 整数测试（质数查找）上限 |
| `-float-iters N` | `3000000` | 浮点测试迭代次数 |
| `-no-warmup` | `false` | 跳过预热 |

流程与旧 Python 版一致：预热 → 整数测试 → 浮点测试 → 换算相对分数。

分数公式：`(基准耗时 / 实际耗时) × 1000`，基准取 i5-8250U 的典型耗时
（整数 1.25 s、浮点 1.15 s）。**不同语言之间不可直接比较**，只在同语言版本间有效。

## diskbench — 磁盘读写吞吐测试

```bash
toolbox diskbench
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-size N` | `1024`（MB） | 测试文件大小 |
| `-block N` | `64`（MB） | 读写块大小 |
| `-file PATH` | 临时文件 | 指定测试文件路径 |
| `-keep` | `false` | 保留测试文件 |
| `-no-drop-caches` | `false` | 不尝试清除系统页缓存 |

流程：写 1 GiB 随机数据 → `fsync` 强制落盘 → （Linux）清页缓存 → 顺序读。

> ⚠️ Linux 上读取速度若接近内存带宽，说明页缓存没清掉。程序会尝试
> `echo 3 > /proc/sys/vm/drop_caches`（需要 root），失败时给出提示。

## diskm — 实时磁盘 I/O 监控

```bash
toolbox diskm
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-device NAME` | 空（全部） | 只监控指定设备 |
| `-interval N` | `1`（秒） | 采样间隔 |
| `-count N` | `0`（无限） | 采样次数 |

数据来源：Linux 直接读 `/proc/diskstats`（**不依赖 sysstat**）；
Windows 暂未实现性能计数器，会输出空表。

## netscan — 局域网设备扫描

```bash
toolbox netscan
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-cidr CIDR` | 自动推断 | 要扫描的网段，如 `192.168.1.0/24` |
| `-timeout MS` | `800` | 单主机探测超时（毫秒） |
| `-workers N` | `64` | 并发探测数 |
| `-ports LIST` | 内置列表 | 要探测的 TCP 端口，逗号分隔 |
| `-out FILE` | 空 | 把结果导出为 CSV |

**两阶段扫描**（与 GUI 版一致）：

1. **存活探测**：先 ping（ICMP），失败则回退到 TCP 端口探测；一旦发现设备立即上报。
2. **信息补全**：后台解析主机名、MAC 地址、开放端口，逐个更新结果。

默认探测端口：`21 22 23 25 53 80 110 139 143 443 445 1433 3306 3389 5432
5900 6379 8022 8080 8443 8888 9000 9090 9200 9999 27017`

## sysinfo — 系统信息

```bash
toolbox sysinfo
toolbox sysinfo --json --target cpu
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--json` | `false` | 以 JSON 输出（字段名与旧 Python 版一致） |
| `--target T` | `all` | `system` / `cpu` / `gpu` / `memory` / `disk` / `all` |

采集自 `gopsutil`（纯 Go），**不需要装 psutil、不需要 WMI 模块**。

## shortcut — 生成网址快捷方式

```bash
toolbox shortcut -name "GitHub" -url "https://github.com"
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-name NAME` | 必填 | 快捷方式名称（非法字符自动清理） |
| `-url URL` | 必填 | 目标网址，必须以 `http://` 或 `https://` 开头 |
| `-dir PATH` | 桌面 | 保存目录 |
| `-format FMT` | `auto` | `auto` / `bat` / `url` / `desktop` |

按平台自动选择：`Windows` → `.bat`（与旧脚本一致），`Linux` → `.desktop`；
显式指定 `-format url` 可生成 Windows Internet Shortcut（双击行为更规范）。

## usb — USB 设备列表

```bash
toolbox usb
toolbox usb --markdown usb.md
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--json` | `false` | 以 JSON 输出 |
| `--markdown FILE` | 空 | 写入 Markdown 快照 |
| `-monitor` | `false` | 持续监控插拔事件 |
| `-interval N` | `2`（秒） | 监控轮询间隔 |

Linux 读 `/sys/bus/usb/devices`，Windows 调用 `Get-PnpDevice`。

## share — 局域网文件共享

```bash
toolbox share -dir D:\共享 -addr 0.0.0.0:8000
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-dir PATH` | `.` | 要共享的目录 |
| `-addr ADDR` | `0.0.0.0:8000` | 监听地址 |

启动后终端会打印本机与局域网访问地址，用浏览器打开即可。

**API**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/files[/{path}]` | 列出目录内容 |
| `POST` | `/api/download/batch` | 多选打包成 zip 下载，请求体 `{"paths":["a.txt","dir/"]}` |
| `GET` | `/api/health` | 健康检查 |

所有路径都会被规范化并校验**必须落在共享根目录内**，防止 `..` 越权访问。

## monitor — 开发板性能监视器

```bash
toolbox monitor -addr 0.0.0.0:8888
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-addr ADDR` | `0.0.0.0:8888` | 监听地址 |
| `-interval N` | `1`（秒） | 状态推送间隔 |

**API**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/status` | 一次性状态快照（JSON） |
| `GET` | `/api/stream` | SSE，持续推送系统状态 |
| `GET` | `/api/ping/stream?target=1.1.1.1` | SSE，持续推送到目标的 ping 延迟 |

适合部署在 RDK / Jetson 等 Linux 板子上，用手机或另一台电脑看实时负载。

## netspeed — 局域网网速测试

```bash
toolbox netspeed -port 7777
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-port PORT` | 环境变量 `PORT` 或 `7777` | 监听端口 |
| `-quiet` | `false` | 不写日志文件 |

浏览器打开后可以选择**下载 / 上传 / 双向**三种模式，通过 WebSocket 实时显示速率。
服务端主动推送 64 KiB 随机数据块，前端计算 Mbps 吞吐。
