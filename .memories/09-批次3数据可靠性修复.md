# 批次 3：数据可靠性 / 一致性 / 体验优化（2026-11-05）

## 关键结论

### 统一原子写入（`internal/data/atomic.go`）
- `SaveJSONAtomic(path, v)` / `SaveFileAtomic(path, []byte)`：`.tmp` → 备份为 `.bak` → 原子 rename。
- `LoadJSONWithBackup(path, &v)`：主文件缺失/损坏时回退 `.bak`，返回 `usedBackup`。
- 已接入：`config.go`（SaveConfig/LoadConfig）、`template.go`（SaveTemplates）、
  `history.go`（SaveHistory/LoadHistory）、`storage.go`（legacy 迁移）、
  `mobile/store.go`、`mobile/chat_store.go`、`chat/chat.go`（historySave）。
- 效果：写盘中断不会留下半截 JSON；主文件损坏可从 `.bak` 恢复。

### 桌面保存反馈
- `internal/ui/app.go` 的 `saveWithFeedback()` 是「立即保存」唯一入口。
- `shortcuts.go` 的 Ctrl+S / Cmd+S 调用它，只有成功才提示已保存。
- `aisettings.go` 的 `OnSave` / `OnSaveProviders` 返回 error；`Save()` 只调
  `OnSaveProviders` 一次（避免两次写盘），失败显示原因。

### 统一 AI 客户端（`internal/ai`）
- 桌面 `internal/chat` 与 Android `internal/mobile` 都改为调用 `ai.Stream` /
  `ai.StreamWithOptions`；`buildUpstreamMessages` 委托 `ai.BuildMessages`；
  测试连接用 `ai.ListModels`。
- SSE 解析：空行切事件、事件内多行 `data:` 拼接、`[DONE]`/注释行跳过，
  `scanner.Err()` 作为错误返回，支持取消与 usage，非流式自动回退。
- 之前桌面端多行 `data:` 处理不完整且吞掉读取错误，已修复。

### 服务商 ID
- `AIProvider.ID` 稳定唯一（旧配置用内容哈希补齐）；`DeleteProvider` 按 ID
  保持选中；`SelectProvidersByID(list, activeID)`、`FindProvider(id)`。

### Android 会话
- `SessionList`：置顶优先，其余 `UpdatedAt` 倒序；`SearchSessions`（标题/正文）、
  `TogglePin`；`chat.go` 下拉框加搜索框 + 置顶按钮 + 相对时间。

### Android 保存状态
- `store.SaveState`：Idle/Pending/Saving/Saved/Failed + `Label()`；
  `SetSaveResultHandler` 回调（去抖保存失败会上报）；editor 页状态栏显示。

### 网页 PGM 归一化（`docs/tools/mapview.html`）
- P5 8 位分支此前 `out.set(subarray)` 未按 maxv 换算 → maxv=15 整图偏暗。
- 现按 maxv 归一化（`v>=maxv→255`，否则 `v*255/maxv`），与 `internal/render/pgm.go` 一致。
- 新增测试钩子 `window.__decodePGM(bytes)`。
