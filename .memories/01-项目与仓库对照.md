## 结论
当前目录 `E:\DesktopData\app\提示词复合工具箱-native` 就是仓库
`https://github.com/XiaoYuyu520520/Copy-Paste-Mutools.git` 的本地克隆。

- remote `origin` 指向该地址
- 本地 `HEAD` = `3f0feac75193a6e6d1c60946ffb3cad9d38b6390`
- GitHub API `commits/main` 返回同一 SHA，工作区干净 → 内容与 `main` 一致
- 本机 `git fetch` 有 TLS 报错（`SSL routines::unexpected eof while reading`），
  但通过 GitHub API 核对 SHA 可确认无差异；如需 fetch 可重试或检查代理/网络

## 项目构成
Go 多模块工程：
- `cmd/merger` 桌面端（Fyne）：提示词合并、模拟键盘键入、文件夹树、
  Markdown 渲染、PGM 地图、局域网扫描、AI 聊天、亮暗主题
- `cmd/toolbox` 命令行：tree / cpubench / diskbench / diskm / netscan /
  sysinfo / shortcut / usb / share / monitor / netspeed
- `cmd/paint` 画板；`cmd/android` + `internal/mobile` 手机端（5 页导航）
- `internal/`：data、ui、render、chat、netscan、lanscan、netspeed、toolbox
- `legacy/python/`：旧 Python 源码归档，不参与构建
- `.github/workflows/`：build / release / android CI

技术栈：Go 1.25+、Fyne v2.8、gopsutil v4、gorilla/websocket、标准库。
