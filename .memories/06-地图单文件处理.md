# 地图页单文件处理：仅 YAML → 编辑器，仅 PGM → 像素测量（2026-11-02）

## 需求
`docs/tools/mapview.html` 之前只接受“必须带 .pgm”，单独拖 .yaml 会被拒绝。
改为：
- **只有 .yaml** → 打开 YAML 编辑器
- **只有 .pgm** → 正常预览 / 擦除 / 导出，距离退化为像素
- **两个都有** → 完整地图查看器（比例尺 + 米制测距）

## 实现
### YAML 编辑器（新增 `#yamlPane`）
- 文本域编辑完整 YAML，按钮：校验 / 复制 / 下载 .yaml / 应用到当前地图 / 关闭
- 校验基于 `parseYAML` 检查 `image`、`resolution>0`、`negate 0/1`、
  `occupied_thresh (0,1]`、`free_thresh < occupied_thresh`
- 有地图时顶栏出现「编辑 YAML」按钮：无 yaml 时生成模板，有则载入 `info.raw`
- 「应用到当前地图」只更新元数据，不重绘/不丢擦除结果，随后刷新比例尺与测距单位
- Ctrl+S 下载、Ctrl+Enter 应用
- 先开 YAML 编辑器再拖入 .pgm：会复用已载入的 YAML（`!state.img && state.info.raw`）

### 仅 PGM
- 不再禁用测量：`btnM` 文本变「像素测量」，测距标注为 `px`
- 比例尺仍只在有 resolution 时绘制
- 保存逻辑保持：`.yaml` 无 `image` 行时自动补一行

### 状态/UI
- `state.yamlName`、`state.pgmOnly` 新增
- `showYamlPane` 按 `state.img` 决定是否显示「应用」按钮
- 关闭编辑器：有地图回到地图，无地图回到空状态
- 空状态文案、README、docs/index 描述同步更新

## 验证
- 内联脚本 `node --check` 通过
- 抽取 `parseYAML` 在 Node 实测：引号 + 行尾注释、origin 小数、阈值默认值正确
- 线上等待 Pages `built` 后 curl 页面确认新文案/结构

## 注意
- YAML 校验只覆盖 map_server 常用字段，不是完整 YAML 解析器
- 仅 YAML 模式不会写回文件，需点下载
- 仅 PGM 时没有真实尺度，`px` 距离仅供相对参考
