# 在线工具的离线下载 / 反馈入口（2026-11-02）

## 需求
在 GitHub Pages 工具里提示：
- 需要离线部署 → 去 Releases 下载桌面 / 命令行 / Android 版本
- 有需求 / Bug → 到 GitHub Issues 提交

## 实现
### 1. 全局右下角提示条（common.js 注入）
- `docs/tools/common.js` 末尾 IIFE：往 body 插入 `.gh-bar`
- 两个链接：`离线版下载` → Releases，`需求 / Bug 反馈` → Issues（新窗口 noopener）
- 关闭按钮写 `localStorage["ghBar.hidden"]="1"`，刷新后不再出现
- 样式在 `common.css` 的 `.gh-bar`，移动端变为底部通栏
- 所有引用 common.js 的页面自动生效：
  base64 / qrcode / codec / markdown / mapview / tools 总览

### 2. 总览页显式横幅
`docs/tools/index.html` 新增 `.offline` 卡片：
「需要离线部署？」+ 两个按钮（下载离线版 / 提交需求 · Bug）

### 3. 全屏工具页提示
- `markdown.html` 空状态卡片底部：Releases / Issues 链接
- `mapview.html` 空状态底部：Releases / Issues 链接

### 4. README
在线工具区补一行：离线部署去 Releases，需求/Bug 提 Issue。

## 附带修复
- `mapview.html` 之前调用了 `copyText` 但没引入 common.js（YAML 复制会报错）；
  现在引入 `common.css` + `common.js`，并给复制操作补 `setYamlResult` 反馈
- markdown/mapview 的 toast z-index 提到 70，避免被右下角提示条盖住
- common.css 补 `@media print { .gh-bar{display:none} }`

## 注意
- 提示条只需引入 common.js，无需各页重复写 HTML
- 用户关闭后持久隐藏；如需再次显示，清 `ghBar.hidden` 或加 `?` 参数（未实现）
- 外部链接统一 `target="_blank" rel="noopener"`
